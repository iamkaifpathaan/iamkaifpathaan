# Profile Maintenance Guide

## Scope

This repository is the GitHub profile landing page for **iamkaifpathaan** and is intentionally minimal.

## Update workflow

1. Update `README.md` content and links.
2. Preserve `assets/banner-dark-animated.svg` as the hero banner source.
3. Keep visual tone minimal and engineering-focused.
4. Let `.github/workflows/snake.yml` regenerate `assets/github-contribution-grid-snake.svg` daily.

## Placeholder checklist

Before publishing major updates, replace placeholders in `README.md` for:
- Project repository URLs
- LinkedIn URL
- Portfolio URL
- Contact email
